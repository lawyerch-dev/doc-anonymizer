# Agent Note: 命中敏感信息的 PDF 页整页栅格化

Status: implemented

## 问题

给 PDF 涂黑的直觉做法是"在文字层上盖黑块"。看上去有效 —— 但**原文仍在内容流里**：
可以选中、可以复制、可以搜索，等于没脱敏。

## 决策

- **命中的页整页栅格化**：该页变成位图，文字层消失（不可选中/搜索/再编辑）；
- **未命中的页原样保留**矢量文字与体积（早期版本是"整份变图片"，见 `docs/architecture.md` §六）。

## 证据

`packages/docanon-core/tests/test_pdf_output.py`：命中页必须没有可提取文字，未命中页必须保留文字层。
设计背景见 `docs/specs/2026-10-05-doc-anonymizer-design.md`。

## 影响与代价

命中页不能再编辑文字、体积上涨。这是**用可编辑性换来的安全保证**，README「已知限制」对用户直说。

## 教训

凡是"看起来已经遮住"的脱敏动作，都要问：**底层数据还在不在**？黑块只是显示层，内容流才是数据层。
